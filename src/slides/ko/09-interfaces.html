일관된 업무 흐름.

System Agent는 외부 메시지를 표준 요청·이벤트로 변환합니다.
채널별 접수·완료·오류·복구의 계약을 함께 정합니다.

01 / REQUEST & RESPONSE

API 요청·응답

업무 요청과 조회, 기준정보 동기화에
필요한 요청·응답 구조를 검토합니다.

02 / MESSAGE & EVENT

비동기 메시지·이벤트

상태 변화와 실행 결과를 전달하는
메시지 구조와 순서·중복 기준을 정합니다.

03 / LEGACY & BATCH

파일·레거시 연동

기존 전송 방식과 데이터 형식을 확인하고
배치·실패·재처리 조건을 협의합니다.
